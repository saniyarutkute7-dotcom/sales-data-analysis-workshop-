# Sales Data Analysis & Visualization

## 📌 Project Overview

This project was completed as part of a **2-day hands-on workshop on Data Analysis & Visualization with AI Tools**.

The project focuses on analyzing a sales dataset using **Python and Jupyter Notebook**. The dataset was cleaned, explored, analyzed, and visualized to understand sales patterns and generate meaningful insights.

## 🎯 Objectives

- Understand and explore a sales dataset
- Clean and preprocess the data
- Identify missing values and duplicate records
- Perform Exploratory Data Analysis (EDA)
- Analyze sales based on different categories
- Analyze payment methods and sales channels
- Study relationships between numerical variables
- Create meaningful data visualizations
- Generate insights from the dataset

## 🛠️ Technologies & Tools

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- AI Tools

## 📊 Dataset

The sales dataset contains **93 rows and 15 columns** with information such as:

- Order ID
- Customer ID
- Customer Name
- Email
- City
- State
- Order Date
- Product
- Category
- Quantity
- Unit Price
- Discount
- Total Amount
- Payment Method
- Sales Channel

## 🧹 Data Cleaning

The dataset was cleaned and prepared for analysis using Pandas.

The following operations were performed:

- Checked the number of rows and columns
- Inspected the structure and data types
- Checked for missing values
- Checked for duplicate records
- Converted `order_date` into datetime format
- Converted `unit_price` into numeric format
- Converted `total_amount` into numeric format
- Removed extra spaces from city names
- Removed duplicate records based on `order_id`
- Removed rows containing missing values
- Saved the cleaned data for further analysis

## 🔍 Exploratory Data Analysis

The cleaned dataset was analyzed to understand different aspects of sales data.

### Revenue by City

Calculated the total revenue generated by each city using Pandas `groupby()`.

### Revenue by Category

Calculated total revenue for different product categories.

### Payment Method Analysis

Analyzed the number of transactions made using different payment methods, including:

- Credit Card
- Debit Card
- UPI
- Net Banking
- Cash

### Correlation Analysis

Analyzed the correlation between numerical variables such as:

- Quantity
- Discount
- Total Amount

### Monthly Order Analysis

Analyzed the number of orders for different months using the order date.

### Product Sales Analysis

Calculated and compared total sales for individual products.

## 📈 Data Visualization

Different visualizations were created using **Matplotlib and Seaborn**.

### Monthly Sales

A line chart was created to visualize total sales over time.

### Sales by Category

A bar chart was created to compare sales across product categories.

### Payment Method Distribution

A pie chart was created to show the order share of different payment methods.

### Order Quantity Distribution

A histogram was created to understand the distribution of order quantities.

### Sales by Channel

A horizontal bar chart was created to compare sales across different sales channels.

### Top Products by Sales

A Seaborn bar plot was created to visualize products based on their total sales.

### Payment Method Count

A Seaborn count plot was used to visualize the number of transactions for each payment method.

### Unit Price Distribution

A Seaborn box plot was created to visualize the distribution of unit prices across different categories.
